# Contributing to CodeX

Thanks for wanting to contribute! Here's how:

## Reporting Bugs
- Open an issue with a clear title and steps to reproduce.
- Include your OS, Ollama version, and model name.

## Submitting PRs
- Fork the repo, create a branch, make your change.
- Keep commits small and descriptive.
- Open a PR against `main`.

## Code Style
- Python: follow PEP 8.
- Bash: use `shellcheck`.
- Keep comments short and useful.

## Testing
- Run untested code inside the Docker sandbox.
- Never test sketchy code on your host.
